### 프로그램 구조

> 자바 프로그램은 패키지(`package`) 안의 클래스(`class`)로 이루어지고, 실행은 `main` 메서드에서 시작한다. 이클립스에서 프로젝트를 만들고 `src`에 패키지와 클래스를 만들어 실습한다.

<br>

```java
package Ch00;                                  // 패키지명

public class HelloWorld {                      // 클래스 선언부(객체지향 문법 영역)
    public static void main(String[] args) {   // main 메서드(절차지향 문법 영역)
        System.out.println("HelloWorld");      // 라이브러리 메서드
    }
}
```

<br>

| **키워드** | **설명** |
| --- | --- |
| `public` | 어디서든 접근 가능 |
| `static` | 객체를 만들지 않아도 바로 메모리에 올라가 실행 가능 |
| `void` | 돌려주는 값이 없음 |
| `main` | 가장 먼저 실행되는 메서드 이름 |
| `String[] args` | 실행할 때 전달하는 문자열 배열(변수 이름은 `args`) |

<br>

**메서드 종류**

| **종류** | **설명** |
| --- | --- |
| 라이브러리 메서드 | 미리 만들어져 제공되는 메서드(`System.out.println` 등) |
| 사용자 정의 메서드 | 개발자가 만드는 메서드 |
| `main` 메서드 | 프로그램이 처음 실행되는 메서드 |

<br>

- 예제 코드: [HelloWorld](../JAVA01/src/Ch00Start/HelloWorld.java)

### 출력

> `System.out`은 콘솔에 데이터를 표시하는 표준 출력 객체다. 줄바꿈 여부와 서식 지정 여부에 따라 메서드를 고른다.

<br>

| **메서드** | **설명** |
| --- | --- |
| `print()` | 줄바꿈 없이 출력 |
| `println()` | 출력 후 줄바꿈 |
| `printf()` | 서식문자로 형식을 정해 출력(Print Formatted) |

<br>

| **서식문자** | **설명** |
| --- | --- |
| `%d` | 10진수 정수 |
| `%o` | 8진수 |
| `%x` | 16진수 |
| `%f` | 실수 |
| `%c` | 문자 한 개 |
| `%s` | 문자열 |

<br>

**이스케이프 문자**는 역슬래시와 문자를 합친 제어 문자다.

| **문자** | **설명** |
| --- | --- |
| `\n` | 줄바꿈 |
| `\t` | 탭 간격만큼 이동 |
| `\b` | 한 칸 뒤로 이동 |

<br>

- 예제 코드: [출력과 서식문자](../JAVA01/src/Ch01Variable/C01SystemOut.java)

### 진수

> 2진수는 0과 1만으로 수를 표현하고, 16진수는 `0~9`와 `A~F` 16개 기호로 표현한다. 비트(Bit)는 2진수 한 자리로 정보의 최소 단위다. n비트는 `2^n`개의 수(0부터 `2^n - 1`)를 나타낸다.

<br>

| **진수** | **리터럴 접두사** | **예시** | **서식문자** |
| --- | --- | --- | --- |
| 2진수 | `0b` | `0b10101101` | 없음(`Integer.toBinaryString()`) |
| 8진수 | `0` | `0255` | `%o` |
| 10진수 | 없음 | `173` | `%d` |
| 16진수 | `0x` | `0xAD` | `%x` |

<br>

**2진수에서 10진수로** 자리마다 가중치(`2^7`부터 `2^0`까지 128, 64, 32, 16, 8, 4, 2, 1)를 곱해 더한다.

```
10101100 = 128 + 32 + 8 + 4 = 172
```

<br>

### 음수와 보수

> CPU의 연산장치(ALU)에는 가산기(더하기 회로)만 있어서 뺄셈을 직접 하지 못한다. 그래서 보수(보충해 주는 수)를 더하는 방식으로 뺄셈 결과를 만든다.

<br>

| **용어** | **설명** |
| --- | --- |
| 1의 보수 | 모든 비트를 반전(0은 1, 1은 0) |
| 2의 보수 | 1의 보수에 1을 더한 값. 음수 `-B`는 `B`의 2의 보수 |
| 뺄셈 | `A - B = A + (B의 2의 보수)`. 넘치는 자리의 1은 버린다 |
| 부호 비트 | 부호가 있는 타입(`byte`, `short`, `int`, `long`)은 맨 앞 비트가 0이면 양수, 1이면 음수 |
| unsigned | 부호가 없는 타입은 `char`뿐이며 맨 앞 비트도 크기를 나타낸다 |

<br>

```
  00000101  = 5
+ 11111011  = 5의 2의 보수(-5)
-----------
(1)00000000 = 0   <- 넘치는 1은 버린다
```

<br>
