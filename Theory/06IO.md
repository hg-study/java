### I/O 스트림

> I/O 스트림은 데이터가 들어오고 나가는 통로이다. 파일, 네트워크, 콘솔 같은 외부 장치와 데이터를 주고받는 표준화된 방법이다.

<br>

| 특징 | 설명 |
|---|---|
| 단방향 | 한쪽 방향으로만 흐름. 입력용과 출력용이 따로 있음 |
| FIFO | 먼저 들어간 데이터가 먼저 나오는 순차 흐름 |
| 일회성 | `close()`로 닫으면 다시 쓸 수 없음 |
| 결합성 | 기본 스트림에 보조 스트림(Buffer 등)을 끼워 성능을 높일 수 있음 |

<br>

| 구분 | 단위 | 클래스 | 대상 |
|---|---|---|---|
| 바이트 스트림 | 1바이트 | `InputStream`, `OutputStream` | 이미지, 동영상, PDF 같은 모든 파일 |
| 문자 스트림 | 문자 | `Reader`, `Writer` | 텍스트(한글) |

<br>

> 처리 순서는 스트림 열기, 읽기와 쓰기, 버퍼 비우기(`flush`), 스트림 닫기(`close`)이다. 스트림은 연 순서의 역순으로 닫는다. 예제는 `C:\IOTEST` 폴더를 미리 만들어 두고 실행한다.

<br>

### 문자 스트림

> `FileWriter(경로, true)`는 파일로 내보내는 문자 스트림이다. `true`면 기존 내용 뒤에 이어쓰기(Append), `false`(기본값)면 지우고 새로 쓰기(Overwrite)이다. `write()`는 내용을 내부 버퍼에 임시 저장하고, `flush()`는 버퍼에 남은 내용을 내보내며, `close()`는 자원을 반납하면서 `flush`도 호출한다.

<br>

> `FileReader`의 `read()`는 한 글자를 읽어 `int`로 돌려주고 더 읽을 데이터가 없으면 -1이다. `while ((data = fin.read()) != -1)`처럼 조건식 안에서 읽어 대입하는 형태가 가장 간결하다.

<br>

```java
Writer fout = new FileWriter("C:\\IOTEST\\test1.txt", true);
fout.write("HELLOWORLD\n");
fout.flush();
fout.close();

Reader fin = new FileReader("C:\\IOTEST\\test1.txt");
int data;
while ((data = fin.read()) != -1) System.out.print((char) data);
```

<br>

> 한 글자씩 읽으면 디스크에 여러 번 접근해 느리므로 `char[]` 버퍼에 한꺼번에 담아 읽으면 빨라진다. 이때 마지막 반복에 이전 값이 남아 섞이지 않도록 `append(buff, 0, 읽은 개수)`로 읽은 만큼만 추가한다. 시간은 `System.currentTimeMillis()`의 차이로 잰다.

<br>

### 바이트 스트림

> `FileInputStream`과 `FileOutputStream`은 파일을 바이트 단위로 읽고 쓴다. `byte[]` 버퍼로 읽으면 빠르고, 쓸 때는 `write(buff, 0, 읽은 개수)`로 읽은 만큼만 쓴다. 문자열은 `getBytes(StandardCharsets.UTF_8)`로 바이트 배열로 바꿔 쓴다(한글은 1문자 3바이트).

<br>

```java
InputStream fin = new FileInputStream(PATH + args[0]);
OutputStream fout = new FileOutputStream(PATH + args[1]);
byte[] buff = new byte[4096];
int data;
while ((data = fin.read(buff)) != -1) {
    fout.write(buff, 0, data);
}
```

### 보조 스트림

> 보조 스트림은 기본 스트림에 덧붙여 기능을 더하는 스트림이다.

<br>

| 보조 스트림 | 기능 |
|---|---|
| `InputStreamReader`, `OutputStreamWriter` | 바이트 스트림을 문자 스트림으로 변환 |
| `BufferedReader`, `BufferedWriter` | 버퍼를 더해 성능을 높임. `readLine()`으로 한 줄 읽기 |
| `PrintWriter` | `println`으로 줄바꿈과 함께 쓰기 |
| `DataInputStream`, `DataOutputStream` | 문자열(`writeUTF`), 실수, 정수를 자료형 그대로 쓰고 읽기. 쓴 순서대로 읽어야 함 |
| `ObjectInputStream`, `ObjectOutputStream` | 직렬화한 객체를 통째로 쓰고 읽기 |

<br>

> 직렬화는 객체를 바이트로 바꿔 파일이나 네트워크로 보낼 수 있게 하는 것이다. `Serializable`을 구현하고 `serialVersionUID`로 버전을 구분한다. 더 읽을 객체가 없을 때 `readObject`를 호출하면 `EOFException`이 발생하므로 처리해 읽기를 끝낸다.

<br>

### 웹에서 가져오기

> `URL.openStream()`은 주소의 내용을 바이트 입력 스트림으로 열어 웹 페이지를 읽는다. 보조 스트림으로 버퍼와 문자 변환을 더해 HTML 파일로 저장할 수 있다.

<br>

> Jsoup은 HTML을 가져와 CSS 선택자로 요소를 뽑는 크롤링 라이브러리이다. `Jsoup.connect(주소).userAgent(...).get()`으로 DOM(`Document`)을 얻고 `getElementsByTag("img")`로 이미지 요소를 뽑아 `src` 주소를 내려받는다. `userAgent`는 브라우저의 Request Headers에서 복사한다.

<br>

> Selenium은 브라우저를 코드로 자동 조작하는 라이브러리이다. `ChromeDriver`로 크롬을 열고 `findElement(By...)`로 요소를 찾아 `sendKeys`로 입력하고 `click`한다. 새 창 링크는 JavaScript로 `target` 속성을 제거해 같은 창에서 열고, 결과 영역의 `outerHTML`을 모아 HTML 파일로 저장한다.

<br>

<span style="color:brown">필요한 jar 는 `JAVA03/lib/` 에, ChromeDriver 는 `src/Drivers/` 에 함께 올려 두었다. `.classpath` 가 `lib/` 의 jar 를 가리키므로 이클립스로 가져오면 바로 쓸 수 있다. 버전을 올리거나 직접 받으려면 아래 표를 참고한다.</span>

<br>

| 라이브러리 | 사용한 버전 | 내려받는 곳 | 쓰는 예제 |
|---|---|---|---|
| MySQL Connector/J | 9.7.0 | https://dev.mysql.com/downloads/connector/j/ (Platform Independent ZIP) | JDBC |
| Jsoup | 1.22.2 | https://jsoup.org/download | `C09Jsoup` |
| Selenium | 4.43.0 (server jar) | https://www.selenium.dev/downloads/ | `C10Selenium` |
| ChromeDriver | 설치한 크롬과 같은 버전 | https://googlechromelabs.github.io/chrome-for-testing/#stable | `C10Selenium` |
| Jackson | 2.21 (core, databind, annotations, datatype-jsr310) | https://mvnrepository.com/artifact/com.fasterxml.jackson.core/jackson-databind | `C11RestApi` |

<br>

> 직접 추가하는 순서는 다음과 같다.

<br>

1. 위 표의 주소에서 jar 파일을 내려받는다(Jackson 은 4개 jar 가 필요하다).
2. 이클립스에서 프로젝트를 오른쪽 마우스로 눌러 Build Path - Configure Build Path - Libraries - Add External JARs 에서 jar 를 선택한다.
3. ChromeDriver 는 압축을 풀어 `chromedriver.exe` 를 `src/Drivers/` 폴더에 넣는다(코드의 `WEB_DRIVER_PATH` 와 같은 경로).

<br>

- 예제 코드: [ChromeDriver](../JAVA03/src/Drivers/chromedriver.exe)
- 예제 코드: [ChromeDriver 라이선스](../JAVA03/src/Drivers/LICENSE.chromedriver)
- 예제 코드: [ChromeDriver 서드파티 고지](../JAVA03/src/Drivers/THIRD_PARTY_NOTICES.chromedriver)

<br>

<span style="color:brown">크롬 버전과 ChromeDriver 버전이 다르면 Selenium 이 브라우저를 열지 못한다. 크롬 주소창에 `chrome://version` 을 입력해 버전을 확인한 뒤 같은 버전을 받는다.</span>

### REST API와 JSON

> REST API는 주소와 파라미터로 요청하면 JSON으로 응답하는 서비스이다. `HttpRequest.newBuilder().uri(...).GET().build()`로 요청을 만들고 `HttpClient.send`로 보내 `HttpResponse`를 받는다. 응답 본문의 JSON은 Jackson의 `ObjectMapper`로 변환한다.

<br>

> `readTree`는 JSON 구조를 그대로 읽고, `readValue(JSON, 클래스)`는 JSON 구조에 맞춘 자바 클래스로 변환한다. JSON 키와 필드 이름이 다르면 `@JsonProperty`로 연결한다. 대구 맛집, 착한 가격 업소 공공데이터를 사용했다.
