### 산술 연산자

> 사칙 연산과 나머지 연산을 하는 연산자다. 정수끼리 나누면 몫만 남는다.

<br>

| **연산자** | **설명** |
| --- | --- |
| `+`, `-`, `*` | 더하기, 빼기, 곱하기 |
| `/` | 나누기(정수끼리는 몫) |
| `%` | 나머지 |

<br>

**% 연산자의 활용**

| **용도** | **예시** |
| --- | --- |
| 짝수, 홀수 구분 | `n % 2 == 0`이면 짝수 |
| 배수 확인 | `sum % 5 == 0`이면 5의 배수 |
| 자릿수 제한, 끝자리 | `n % 10`은 일의 자리(0~9) |

<br>

나머지의 범위는 `N % 2`가 0~1, `N % 3`이 0~2, `N % 10`이 0~9처럼 나누는 수보다 항상 작다.

<br>

**삼항 연산자** `조건 ? 참일 때 값 : 거짓일 때 값`으로 `if`를 한 줄로 쓴다.

```java
String result = (num1 % 2 == 0) ? "짝수입니다" : "홀수입니다";
```

### 비트 연산자

> 정수를 2진수 비트 단위로 연산한다.

<br>

| **연산자** | **설명** | **예시(15와 20)** |
| --- | --- | --- |
| `&` | 같은 자리가 둘 다 1이면 1 | `15 & 20 = 4` |
| `\|` | 같은 자리 중 하나라도 1이면 1 | `15 \| 20 = 31` |
| `^` | 서로 다르면 1(둘 다 1이면 0) | `15 ^ 20 = 27` |
| `~` | 모든 비트 반전(1의 보수) | `~15 = -16` |
| `<<` | 왼쪽으로 n칸 밀기. `2^n`을 곱한 효과 | `20 << 3 = 160` |
| `>>` | 오른쪽으로 n칸 밀기. `2^n`으로 나눈 효과 | `20 >> 3 = 2` |

<br>

```
15 = 00000000 00000000 00000000 00001111
20 = 00000000 00000000 00000000 00010100
&  = 00000000 00000000 00000000 00000100  = 4
```

### 논리 연산자

> 조건식 두 개를 `&&`(AND) 또는 `||`(OR)로 연결한다. 결과가 이미 정해지면 오른쪽 식을 실행하지 않는다(단락 평가).

<br>

| **연산자** | **설명** |
| --- | --- |
| `&&` | 둘 다 참이어야 참. 왼쪽이 거짓이면 오른쪽을 실행하지 않는다 |
| `\|\|` | 하나라도 참이면 참. 왼쪽이 참이면 오른쪽을 실행하지 않는다 |
| `!` | 참과 거짓을 뒤집는다 |

<br>

```java
int a = 1, b = 1;
boolean c = (++a > 0) || (++b > 0);   // 왼쪽이 참이라 오른쪽은 실행하지 않아 a=2, b=1
```

<br>

### 증감 연산자

> 값을 1 늘리거나(`++`) 줄인다(`--`). 변수 앞에 붙이면 먼저 바꾼 뒤 사용하고(`++a`), 뒤에 붙이면 사용한 뒤 바꾼다(`a++`).

<br>

```java
int a = 5, b = 6, c = 10;
int d = ++a * b--;   // a를 먼저 6으로 올려 6 * 6 = 36 계산 후 b는 5가 됨
```
