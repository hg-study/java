### 스트림

> 스트림(Stream)은 자바 8에 도입된 기능으로, 데이터의 흐름을 표현하며 데이터 소스와 소통하는 중간 매개자이다. 배열, 컬렉션 같은 다양한 데이터를 처리하는 공통된 표준 방법이다. 많은 데이터를 배열이나 컬렉션에 담고 반복문(`for`, `Iterator`)으로 다루던 기존 방식의 한계(가독성 저하, 코드 재사용의 어려움)를 극복하기 위해 등장했다.

<br>

---

### 특징

| 특징 | 설명 |
|---|---|
| 내부 반복 | 컬렉션의 외부 반복(`for`)과 달리 스트림 내부에서 반복 처리함 |
| 일회성 | 데이터를 소비하고 스트림이 닫히면 다시 쓸 수 없음 |
| 원본 불변 | 원본 데이터를 수정하지 않고 처리된 결과만 새로 만듦 |
| 지연 연산 | 최종 연산이 호출되기 전까지 중개 연산은 실제로 수행되지 않음 |

<br>

---

### 처리 구조

> 스트림은 파이프라인 구조로 처리한다. 컬렉션이나 배열에서 스트림을 만들고(생성), 여러 중개 연산을 연결(Chaining)하고, 최종 연산으로 결과를 만든 뒤 스트림이 끝난다.

<br>

```java
List<Integer> li3 = li1.stream()                  // 생성
                       .filter(n -> n % 2 == 1)   // 중개 연산 : 홀수만
                       .map(n -> n * n)           // 중개 연산 : 제곱
                       .collect(Collectors.toList());   // 최종 연산 : List 로 모음
```

<br>

### 중개 연산과 최종 연산

> 중개 연산은 요소를 변환하거나 필터링하며 결과가 스트림이라 여러 번 연결할 수 있다. 최종 연산은 스트림을 소비해 결과를 만든다.

<br>

| 구분 | 연산 | 설명 |
|---|---|---|
| 중개 | `filter` | 조건에 맞는 요소를 선택 (중요) |
| 중개 | `map` | 요소를 다른 형태로 변환 (중요) |
| 중개 | `flatMap` | 각 요소를 변환하고 하나의 스트림으로 평면화 |
| 중개 | `distinct`, `sorted` | 중복 제거, 정렬 |
| 중개 | `limit`, `skip` | 지정 개수만 남김, 처음 몇 개를 건너뜀 |
| 최종 | `forEach` | 각 요소를 반복 처리 (중요) |
| 최종 | `collect` | 요소를 모아 새 컬렉션 생성 (중요) |
| 최종 | `reduce` | 요소를 하나의 값으로 줄임 (중요) |
| 최종 | `min`, `max`, `count` | 최소값, 최대값, 개수 |
| 최종 | `anyMatch`, `allMatch`, `noneMatch` | 하나 이상, 모두, 하나도 조건과 일치하지 않는지 |
| 최종 | `findFirst`, `findAny` | 첫 번째 요소, 임의의 요소 |

<br>

> 객체 목록의 변환 예: `persons.stream().map(person -> new Employee(person)).collect(Collectors.toList())`처럼 `map`으로 다른 클래스의 객체로 바꿔 모은다. 이름의 길이만 구하려면 `map(el -> el.getName().length())`처럼 한 번의 `map`으로도 된다.
